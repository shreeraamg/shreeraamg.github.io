## The idea

Life Grid is a life and age tracker that uses a GitHub-contribution-graph-style visual format. It is designed to be used as a browser homepage: a small tool that puts a familiar grid into a different context.

## What I built

The project uses HTML, CSS, and JavaScript. It brings the tracker and its grid presentation into a hosted page, with the source available publicly.

Unlike the distributed order platform, this project is about a focused personal utility rather than a multi-service architecture.

## The visual approach

A contribution graph is a compact way to represent time. Life Grid applies that visual vocabulary to life and age tracking.

The preview on the portfolio's Projects page is only an illustration. It does not display personal age data; the hosted project is the place to explore the actual tool.
